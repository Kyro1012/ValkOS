# ValkOS

> An Arch-based Linux distribution designed to make the transition
> from Windows to Linux feel natural without sacrificing the power
> of Arch.

## 🚧 Status

ValkOS is currently in early development.

## 🎯 Vision

ValkOS aims to combine:

- Arch Linux's flexibility
- Windows-friendly usability
- Hyprland's Wayland workflow
- A custom desktop shell
- Gaming-first configuration
- Sensible defaults and automated setup

## 🏗️ Architecture

ValkOS is built in layers:

Arch Linux
→ Linux kernel
→ Wayland
→ Hyprland
→ ValkOS desktop shell
→ ValkOS utilities

## 🧪 Development

ValkOS is currently being developed inside an isolated QEMU/KVM
virtual machine to allow experimentation without affecting the
host system.
